# سهل (Sahl)

منصة SaaS للتجار المصريين اللي بيبيعوا بالدفع عند الاستلام.

## الهيكل

| المسار | الوصف |
|---|---|
| `app/` | لوحة تحكم التاجر → Cloudflare Pages |
| `app/css/` | 22 ملف CSS — **الترتيب الرقمي ملزم** (شوف تحت) |
| `app/fonts/` `app/img/` | أصول ثنائية، كانت base64 جوه الـHTML |
| `admin/` | لوحة السوبر أدمن → Cloudflare Pages (نطاق منفصل) |
| `tools/` | أدوات التطوير — مش بتتنشر |
| `CLAUDE.md` | ذاكرة المشروع — **اقراه الأول** |

## ⚠️ ترتيب ملفات الـCSS

البادئة الرقمية في `app/css/` **مش تزويق — هي عقد**. الـselectors دي
معرّفة أكتر من مرة بخصوصية متساوية، فاللي بيكسب هو الأخير:

| Selector | مرات | اللي بيتكسر لو الترتيب اتغيّر |
|---|---|---|
| `.sc` | 4 | كروت الإحصاء بتفقد شريطها الملوّن |
| `.fbar` | 2 | القايمة المنسدلة بتظهر **ورا** الجدول |
| `.bulkbar` | 3 | شريط التحديد بيبان وإحنا مش مختارين حاجة |

كله من غير أي خطأ في الكونسول. `17-card-tweaks.css` لازم بعد
`06-cards.css`، و`19-mobile.css` لازم قبل ملفات البلوك التاني.

**أي ملف جديد ياخد رقم يحدّد مكانه في الـcascade، والـ`<link>` في
`index.html` لازم يتحط في نفس الترتيب.**

## الفحص قبل أي نشر

```bash
./check.sh
```

بيفحص الاتنين `app/index.html` و `admin/index.html`:

| الفحص | النتيجة لو فشل |
|---|---|
| صيغة الجافاسكربت (inline + الملفات الخارجية) بـ `node --check` | فشل |
| كل `href`/`src` محلي بيوصل لملف موجود على الديسك | فشل |
| مفيش IDs مكررة في الـ**markup الثابت** (سترينجات الجافاسكربت مستثناة) | فشل |
| كل `import {x}` بيلاقي `export` مطابق في الملف الهدف | فشل |
| الـCSP في `_headers` متسقة مع وجود inline `<script>` | فشل |
| IDs متولّدة من أكتر من موضع في الجافاسكربت | تحذير |

**متطلبات:** Python 3.8+ و Node.js. Node هنا **linter محلي بس** — مفيش build step، ومحتوى الفولدر هو اللي بينشر زي ما هو.

## النشر

كل فولدر مشروع Cloudflare Pages منفصل. المحتوى المنشور هو محتوى الفولدر نفسه.

⚠️ **الداتابيز والفرونت لازم يتنشروا مع بعض** — تعديل داتابيز من غير نشر الفرونت بيوقّف حاجات من غير سبب واضح.
