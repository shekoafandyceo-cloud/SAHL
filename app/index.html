التكلفة: برقمك الخاص = رسوم الأوردر العادية بس · من رقم سهل الرسمي = جنيه واحد للأوردر (بدل الرسوم العادية مش فوقها) — بيتخصم مرة واحدة والتذكير مجاني.
رقم واتساب خاص بيك (اختياري)

سيب الخانات فاضية عشان تستخدم رقم سهل، أو حط بيانات WhatsApp Cloud API بتاعتك.

🔌

ربط واتساب بميتا

عشان ردود العملاء على أزرار التأكيد ورسايلهم توصلك

  1. افتح Meta App Dashboard وادخل على WhatsApp → Configuration
  2. في خانة Callback URL حط الرابط اللي تحت
  3. في خانة Verify Token حط التوكن اللي تحت
  4. دوس Verify and Save
  5. من Webhook fields فعّل messages

🔒 الرابط والتوكن دول سريين ومخصوصين لمتجرك — متشاركهمش مع حد.

📱

بوت تلجرام

تنبيهات لحظية بكل اللي بيحصل في متجرك

  1. افتح بوت SAHL Operations على تلجرام
  2. ابعت /start
  3. هيبعتلك رقم الـ Chat ID بتاعك
  4. انسخه وحطه هنا 👇
🔔 إيه اللي يوصلك؟
🔗 اربط تلجرام الأول (احفظ الـ Chat ID فوق) وبعدها تقدر تتحكم في التنبيهات.

⚠️ تنبيهات نفاد الرصيد وطلبات الإلغاء بعد التأكيد شغالة دايماً — تفويتها بيوقف شغلك.
